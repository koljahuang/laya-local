# Laya 部署文章

本目录保存 Laya 本地服务与 Amazon SageMaker AI 部署文章及配套素材。

## 文档

- `laya-aws-blog.md`：Markdown 源文件；
- `laya-aws-blog.html`：自包含 HTML，图片、封面帧和视频均已内嵌；
- `aws-blog-head.html`：生成 HTML 时使用的样式。

HTML 可以脱离 `assets/` 单独打开。仓库只保留便于阅读和复现的文本与网页版本，Word、ZIP 和内部检查清单不会提交。

## 素材

- `assets/01-playground-home.png`：Playground 首页；
